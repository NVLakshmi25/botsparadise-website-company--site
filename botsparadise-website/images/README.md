# Images folder

The HTML currently uses BOTSPARADISE image URLs hosted on the original website, so the site can display images without local copies when you are online.

Referenced images include:
- `https://botsparadise.com/img/bots_250_01.jpg` — navbar logo
- `https://botsparadise.com/img/slide_02_bot.jpg` — hero image (fallback: `slide_05_digital.jpg`)
- `https://botsparadise.com/img/project1.jpg` through `project5.jpg` — portfolio/blog images
- `https://botsparadise.com/img/slide_08_analytics.jpg` — analytics portfolio image
- `https://botsparadise.com/img/project3.jpg` — About image

For learning: if you want local image files, save copies you are permitted to use into this folder, then change each HTML `src` from `https://botsparadise.com/img/filename.jpg` to `images/filename.jpg`. This environment could not fetch the remote images, so no fake or empty image files were added.
